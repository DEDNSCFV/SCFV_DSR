§2 · QUÉ ES EL PROGRAMA DE INVESTIGACIÓN SCFV

estudio de la constitución, transformación, formalización, validación y
materialización del conocimiento profesional mediante el desarrollo de
un sistema contable formalmente verificable y fractal.

§4 · ESTRUCTURA DE LA INVESTIGACIÓN

§4.1 · Cadena epistemológica-operacional

  REALIDAD → EVIDENCIA → HECHO → CONOCIMIENTO → VALIDACIÓN
    → EVENTO → CONSECUENCIAS → REPRESENTACIONES → DEMOSTRACIÓN

§4.2 · Separación epistemológica fundamental

  NORMA ≠ INFERENCIA ≠ DECISIÓN ≠ ASIENTO

§4.3 · Unidad contable atómica

  U = N ⊙ M

  N = naturaleza (DEUDORA / ACREEDORA)
  M = movimiento (AUMENTA / DISMINUYE)
  ⊙ = relación formalizada de cargo y abono

  Correspondencia:
    DEUDORA + AUMENTA     → DEBE
    DEUDORA + DISMINUYE   → HABER
    ACREEDORA + AUMENTA   → HABER
    ACREEDORA + DISMINUYE → DEBE

§4.4 · Horizonte epistemológico

  hermenéutico → heurístico → performativo

§4.5 · Antifragilidad (hipótesis)

  ERROR → CONTRADICCIÓN → EVIDENCIA → DECONSTRUCCIÓN
    → TRANSFORMACIÓN → NUEVO CONOCIMIENTO
